# jesse-we-need-to-code
Small Java programs and algorithmic experiments throughout my DSA journey.


This is where I will be dumping my coding experiments, random ideas, and attempts at solving problems in different ways while learning DSA in Java.
This experiment is a square root calculator written in Java, of course. It uses Binary Search and an application of the Newton-Raphson method to approximate square roots without using any built-in square root functions or exponential operators.
